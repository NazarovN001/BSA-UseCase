# Use Case — Сценарии использования

## О проекте
Учебный проект Школы 21 (индивидуально).  
Изучил метод Use Case (варианты использования) — способ описания функциональных требований через сценарии взаимодействия участников с системой. Применил метод на примере системы онлайн-записи для барбершопа.

## Моя роль
- Определил основные и дополнительные действующие лица (акторов) системы
- Описал варианты использования в структурированном формате
- Разработал основные и альтернативные потоки событий
- Выделил связи между UC: включение (include) и расширение (extend)
- Сформулировал предусловия, триггеры, постусловия и гарантии

## Выполненные задачи

### Задание 1 (ex00): Описание варианта использования — актуальное расписание мастеров
- Определил основное действующее лицо (менеджер) и его бизнес-цель
- Описал цель, область действия, предусловия и триггер UC
- Указал минимальные гарантии и гарантии успеха
- Выделил не менее двух дополнительных заинтересованных сторон и их интересы

### Задание 2 (ex01): Описание потоков UC — актуальное расписание мастеров
- Описал основной сценарий со сквозной нумерацией шагов
- Разработал альтернативные сценарии с цифро-буквенной нумерацией
- Применил формат «участник/система + действие + условия»
- Свёл сложные взаимодействия к 4 шагам транзакции

### Задание 3 (ex02): Описание варианта использования — выбор услуг и бронирование слота
- Описал UC взаимодействия клиента с системой для выбора услуг и бронирования
- Выделил отдельный UC со связью «включение» (include) или «расширение» (extend)
- Указал тип связи для каждого выделенного UC

### Задание 4 (ex03): Описание потоков UC — выбор услуг и бронирование слота
- Описал основной и альтернативные потоки функционального взаимодействия клиента с системой
- Описал потоки выделенного(-ых) UC

### Задание 5 (ex04): Описание варианта использования — мастер просматривает расписание и отзывы
- Описал UC взаимодействия мастера с системой для просмотра расписания и отзывов
- Выделил отдельный UC со связью include/extend

### Задание 6 (ex05): Описание потоков UC — мастер просматривает расписание и отзывы
- Описал основной и альтернативные потоки функционального взаимодействия мастера с системой
- Описал потоки выделенного(-ых) UC

- ✅ Выделенные UC со связями include/extend
